# Daily portfolio digest template

Use this exact section order: Ready for explicit merge approval; Low-risk,
easy-to-validate PRs; Work in progress; Needs your decision; Deferred at triage;
Promising next candidates; Operational exceptions. Each entry names the issue,
evidence-backed state, next action, and PR/run links when available. A PR appears
in “Ready” only with passing configured checks and an approved independent review
with no blocking or important findings. State plainly which child PRs, if any,
were merged into a non-default integration branch under a recorded standing
authorization, and that no integration/other PR was merged to the default branch
without explicit human approval naming it.
