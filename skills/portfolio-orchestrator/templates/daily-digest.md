# Daily portfolio digest template

Use this exact section order: Ready for explicit merge approval; Low-risk,
easy-to-validate PRs; Work in progress; Needs your decision; Deferred at triage;
Promising next candidates; Operational exceptions. Each entry must name the
issue, its evidence-backed state, the next action, and links to its PR and run
when available. State plainly that no PR was merged without named human approval.
